# Version History

| **Version 1.2.0** | **FEATURES**<br>- **Magic Rituals:** A third tab has been added to calculate the bonus for a *Magical Ritual* involving one or more participants. It automatically calculates potential modifiers, complementary skills, and sacrifice contributions. Sending the calculation to chat generates a summary card where the GM can apply power point deductions, roll and apply blood (hit) damage, and roll chosen critical sacrifices before prompting the final skill manoeuvre roll.<br>- **Themesd:** Added light and dark colour themes and, in a game setting, added an option to switch the base hue of the theme between gold and teal.<br><br>**IMPROVEMENTS**<br>- Added "Delete" buttons to quickly remove participants directly from the *Boost Skill* and *Group Task* tabs.<br>- Added a "Cancel" button to the "Add Participant" sidebar.<br>- Minor structural alignment and visual improvements to the overall interface.<br><br>**BUG FIXES**<br>- Fixed an issue where invalid user IDs could be passed to Foundry's chat API when generating whispered chat cards. |
