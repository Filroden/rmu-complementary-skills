# Version History

| **Version 1.2.0** | **FEATURES**<br>- **Magic Rituals:** A third tab has been added which will calculate the bonus for a *Magical Ritual* involving one or more participants. It takes account of all the potential modifiers to the ritual, including complementary skills. Once you have completed all the details in the tab and send the roll to chat, the chat card will summarise the bonus (and provide a detailed breakdown). If one or more partipants have choosen a blood (crit) sacrifice, the GM should choose an appropriate critical (default is Puncture), apply any sacrifies and make the roll. This will open the usual skill manoeuvre roll dialogue where other modifiers (armour penalties, existing injuries, etc) will be applied. Applying any sacrifies will deduct any contributed powerpoints from participants, roll any blood (hits) damage and roll any criticals (which will need to be applied to the participants from the resulting crit chat card).<br><br>**IMPROVEMENTS**<br>- Added "Delete" buttons to remove participants on the *Boost Skill* and *Group Task* tabs.<br>- Added a "Cancel" button to the "Add Participant" sidebar to close it.<br>- Minor improvements to the look and feel of the overall interface.<br><br>**BUG FIXES:**<br>- Fixed a bug where an invalid ID could be passed to Foundry's chat API when making a roll. |
